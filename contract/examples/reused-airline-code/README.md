# Reused airline code

Two unrelated airlines that used the same ICAO (`XRC`) and IATA (`X5`) codes at different times.

- They have different `id`s (`al-red-coast`, `al-red-coast-2`); codes are never identities.
- The older one ceased in 2012 with no successor (`successor_id: null`); the newer one was founded in 2015.
- Both search docs contain the terms `XRC` and `X5`, so searching a code returns both. Labels include years to tell them apart.

The airlines, codes, registrations and serial numbers are made up and may coincide with real ones.
