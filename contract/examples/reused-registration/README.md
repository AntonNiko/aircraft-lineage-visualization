# Reused registration

One registration, `D-AXRR`, carried by two different airframes.

- `airbus-a320fam-5001` flew as `D-AXRR` until 2014, then moved to Sample Charter as `SE-RZA`.
- `airbus-a320fam-9901` was built in 2018 and registered as `D-AXRR` with Example Air.
- They stay separate airframes because the ID is based on the serial number, not the registration.
- Both search docs contain `D-AXRR` (one as current, one as past), so searching it returns both aircraft.

The airlines, codes, registrations and serial numbers are made up and may coincide with real ones.
